## <M code="e65f"/> 選考にあたりまして
---
この度は「第一回 RPG-Cobo 作品コンテスト」へのご参加、並びに素晴らしい作品のご応募、誠にありがとうございました！

RPG-Coboという新しいツールの製品発表が6月5日にされ、コンテストの告知と開始が7月9日、締め切りが9月8日と、非常にタイトなスケジュールでの開催となりました。  
東京ゲームショウへの出展ありきでコンテストのスケジュールを組んだのは果たして正解だったのか、運営側としても非常に悩ましいところでした。

しかし、そのような中でも多くの素晴らしい作品が集まりました。**ベータテスト期間内でこのコンテストを開催できたことは、RPG-Cobo にとって非常に有意義な機会となったと思います。**

残念ながら最優秀賞は該当作なしとなりましたが、その次点となりえる作品は多くあり、特別賞の枠を2名から3名に増やすことにいたしました。

## <M code="e0f0"/> 入選作の選評
---

#### 優秀賞：花魔法の庭師～フローラル・ガーデナー～　(スズランさん 作)

今回の応募作の中で一番のボリュームと完成度の高さを誇る作品でした。
後半に行くほどにバトルの難易度が程よく上がっていき、敵キャラはザコキャラ一人一人にも個性があり、ボスには力押しだけでは通用しない。  
魅力的な4人のプレイヤーキャラも能力、装備、スキルが非常にバランスよく設定されており、プレイヤーの戦略性を大いに引き出す作りになっていました。

前半の作りこみ、クエストへの導線を分かりやすくことで、さらに全体の完成度を高くできると思います。

#### 優秀賞：遺禍のルーインズ　(ねっこさん 作)

ローグライクとも言えるバトルシステムを RPG-Cobo の基本イベントシステムで巧みに表現しており、戦略性の高いゲームプレイが楽しめました。
装備の組み合わせによって回避、カウンター、連撃のようなスタイルを選択でき、発動するスキルまで変化するのには驚かされました。  
また、タイトル画面のダンスシーンやオープニングの演出も非常に丁寧で、プレイヤーは世界に引き込まれた状態でプレイすることが出来ます。

今回は最初のボス敵を倒すところまでのデモ版でしたが、是非これからも開発を進めていただきたい作品でした。

#### 特別賞：理の女神　(フク郎さん 作)

この作品は、なんとストーリーボイスが全編にわたって収録されており、キャラクターの魅力が一層引き立っていました。
謎とそれに対する仕掛けと演出、複数ある結末全てがしっかりと結びついており、独自の世界が強烈に表現されていました。

正に驚きの連続のこの作品でしたが、さらに驚くことにAIによるシステムやイベントの構築が巧みに組み込まれていました（私は途中まで気づきませんでした…）。
オープンソースである RPG-Cobo は、AIによる改造がとてもやりやすいことを示す好例といえる作品でした。

#### 特別賞：みつけてクエスト　(るにさん 作)

他の入選作に比べるとシンプルに作成された、しかし、シンプルだからこそ、ゲームの面白さが際立っていました。
サンプルマップなど既存の素材の使い方が非常に上手で、マップやキャラをとても魅力的に紹介する工夫が随所に見られました。
また、ノーマルエンド、トゥルーエンドの両方が用意されており、プレイヤーの謎解きによる結末の変化も魅力的でした。

実は RPG-Cobo のサンプルゲームとして理想的なのではと思わせる秀作でした。

#### 特別賞：Iris Code　(蒼咲もらさん 作)

素晴らしい作品ですが短いのが非常に惜しく、通常の選定基準であれば佳作にとどまるところでした。
ですが、佳作にするには勿体ない魅力のある世界観と特にキャライラストは、これからも開発を進めてぜひ Iris Code を完成させてほしいという思わせるのに十分であり、
入賞枠を一つ増やし、特別賞とさせていただきました。

夢の世界も現実の世界も、RPG-Cobo の表現力をとてもうまく引き出してとても幻想的で美しい世界を作り上げています。

##### 選外佳作の選評

**シレンくんの小冒険譚**：　ワンクエストのショートストーリーですが、バトルバランスやイベントシーンの演出などがとても完成度が高く、
このまま作り上げていけば大作になりそうな可能性を感じる作品でした。

**アイシャの借金返済計画**：　ミニゲームとして申し分のない面白さを持っていました。また左下にアイシャのイラストが常に表示されていて、表情の変化を見るだけでも楽しい作品でした。
ぜひ難易度をさらに上げた続編を作ってもらえたらと願っています。

**聖なるUNK●を目指せ**：　自由なパーティ編成とランダムダンジョンの要素が特徴的な作品でした。
演出や遊びやすさなども工夫されており、ゲームシステムとして非常に優れた作品でした。

**メスガキアスレ（仮）**：　純粋なアスレチックゲームとなっています。RPG-Cobo の「動く地形」システムをとても有効に使い面白く高難度に仕上がっています。
難しくてノーミスクリア出来なかったので、ズルをしてゴールまでハシゴを渡してクリアしましたが、なんと次の面もありました！（流石にそちらは制作途中でした。）  
RPG-Cobo でアスレチックゲームを作る可能性を強く感じさせる作品でした。

**ネコちゃんクエスト**：　複数のミニゲームを集めた作品で、RPG-Coboの色々な機能を意欲的に活用してくれました。また、ボーナスステージを始め遊び心も随所に見られました。  
難易度をもっと上げて、やりごたえのあるゲームにするともっと楽しくなると思います。

**RE:FRAME DOLL**：　AIを使いこなし、ゲームUIをほぼ作り変え、パーツ組み換えでキャラを作ったり戦闘陣営が指定出来たりと、
RPG-Cobo の基本システムを大幅に拡張しており、今後どこまですごい作品に発展していくのか非常に楽しみな作品でした。


## 終わりに

今回のコンテストでは、やはり時間的な制約のためか長編RPGはあまりないか途中で終わってしまう作品が多く、コンパクトにまとまった作品が相対的に評価されやすい傾向がありました。
今回惜しくも選出されなかった作品につきましても、時間がもう少しあれば十分な完成度の作品になったであろうと感じさせるものが多くありました。

この点を反省して、次回からはどんなタイプの作品でも余裕をもって投稿できるようにコンテストのルールや期間を整備していきたいと考えています。

そして、やはり言及すべきはAIを活用した作品が複数あった点です。AIの活用で凄い作品を生み出すポテンシャルが広がった一方で、通常では発生しない不具合やデメリットも見受けられ、
AI使用の難しさや大変さも感じられました。この点はツール側でももう少しサポートできる部分が無いか、検討していきたいと思います。

最後に、今回のコンテストを通じたフィードバックで得られた学びは計り知れなく、今後の RPG-Cobo の開発にとって非常に貴重なものとなるでしょう。  
次回のコンテストの際には、RPG-Cobo はさらに進化し、最高のRPG制作ツールにより近づいていることをお約束します。

それでは、次回のコンテストへのご参加を心待ちにしています。
