RPGを作るうえで、**変数** は非常に重要な役割を果たします。ゲームがどこまで進んだかを保存する変数、宝箱を開けたかどうかを記録する変数、ゲームのプレイ時間やプレイヤーの所持金も変数です。

このページでは、RPG-Coboの **変数** について詳細に掘り下げて解説します。

### <M code="f10d"/> 変数の種類
---

RPG-Coboのイベントコマンドで使用できる変数は以下の種類があります。

|変数のタイプ|変数名|概要|
|------------------|------------|-------|
|ワーク変数|W X Y Z|イベントの処理中に使用可能な一時的な変数（保存されない）|
|イベント変数|A B C D|個々のイベントに保存される変数|
|グローバル変数|G000 ~ G999|全てのイベントから読み書きできる変数|
|システム変数|MONEY PTIME MAPID…|所持金、プレイ時間、現在のマップIDなど、ゲームのシステムの状態を取得できる変数|
|ボタン状態|BTN_UP BTN_LEFT BTN_A…|ボタンが押されているかを取得できる変数|
|クエリ変数|NUM_I000 NUM_E000...|アイテムの所持数、敵の撃破数などを取得できる変数|

#### <M code="ea50"/> ワーク変数って何？

ワーク変数は、イベントの処理中に一時的に使用される変数です。イベントが終了すると値は保持されず、次回のイベント実行時には初期化されます。例えば計算結果を一時的に保存したりする場合に便利です。

また、**マクロイベントを呼び出す際にワーク変数は重要な役割を果たします**。呼び出し元のイベントからワーク変数に値を設定しておくことで、マクロイベント内でその値を利用することができます。  
さらに、マクロイベント終了時の`W`の値は戻り値として呼び出し元のイベントに返されます。「<M code="eb8e"/>マクロ実行」コマンドを使用してマクロイベントを呼び出す際に、この仕組みを活用することができます。

#### <M code="ea50"/> 読み書き可能な変数と、読み込み専用の変数

RPG-Coboの変数には、読み書き可能なものと、読み込み専用のものがあります。

- ワーク変数、イベント変数、グローバル変数は読み書き可能です。
- システム変数、ボタン状態、クエリ変数は基本的に読み込み専用です。システム変数のいくつかの値は書き込み可能です。

#### <M code="ea50"/> セーブデータ間で共有されるグローバル変数

グローバル変数には、「セーブを共有」という設定があり、これを有効にすると、セーブデータ間を跨いで同じ値を保持・設定することができます。これはクリアフラグのような、セーブデータ間で共有されるべき情報を保持するのに便利です。

データベースの「<M code="ea28"/>ゲーム設定」から「<M code="e16e"/>グローバル変数」で設定画面を開くことが出来ます。


### <M code="f10d"/> 変数の値を変更する方法
---

カスタムイベントの編集やマクロイベントの編集画面で、変数の値を変更するためのイベントコマンドを設定することができます。

#### <M code="ea50"/> イベントコマンド「<M code="ea5f"/>変数の設定」
一般的に、変数の値を変更するにはイベントコマンド「<M code="ea5f"/>変数の設定」を使用します。グラフィカルに左辺値、操作、右辺値を指定して変数の値を設定することができます。

<div class="sspart">
<SS src='docs/variables-1.png' alt=''/>
- 左辺値: 変更したい変数を指定します。
- 操作　: `＝` `＋` `ー` `×` `÷` `％` の中から選びます。  
  - `＝`は右辺値をそのまま代入します。
  - `＋`は右辺値を左辺値に加算して左辺値に代入します。`ー` `×` `÷` `％`も同様です。
- 右辺値: 色々な種類の値を指定できます。
  - <M code="e9f6"/> ON/OFF: ONまたはOFFの値を指定します。スイッチの状態に使います。
  - <M code="e0bc"/> 数値: 任意の数値を指定できます。
  - <M code="e167"/> 文字列: 任意の文字列を指定できます。
  - <M code="eb40"/> 乱数: 任意の範囲で乱数を指定できます。
  - <M code="eb8e"/> スクリプト: 任意のスクリプトを指定できます。複雑な数式や複数の変数を組み合わせた計算などで使用します。
  - <M code="e322"/> 変数の選択: 他の変数の値を右辺値として指定できます。
  - <M code="f120"/> データID: 任意のデータIDを指定できます。アイテムや敵などのデータを参照する際に使用します。
</div>

#### <M code="ea50"/> イベントコマンド「<M code="eb8e"/>スクリプト実行」

「<M code="ea5f"/>スクリプト実行」コマンドは、この中に何でもプログラムを記述することができる強力なコマンドです。
もちろん、変数の値を取得したり変更したりすることも可能です。

***ただし、スクリプト実行は自由度が高い分、記述を間違えるとイベントが正しく動作しなくなる可能性があるため、慎重に使用しましょう。***

<SS src='docs/variables-2.png' alt=''/>


### <M code="f10d"/> 変数をイベントで使う方法
---

#### <M code="ea50"/> 条件判定に変数の値を使う
例えば、あるキャラの出現条件として変数を使用したり、イベントコマンドの条件分岐等で変数の値を判定したりすることができます。

<SS src='docs/variables-3.png' alt=''/>

「変数を比較…」を選択すると、指定した変数の値を他の値と比較する条件を設定することができます。

#### <M code="ea50"/> イベントのパラメータに変数を使用する
例として、「<M code="f109"/>アイテムの増減」コマンドで、増減させるアイテムの個数を変数で指定してみます。

<div class="sspart">
<SS src='docs/variables-4.png' alt=''/>

1. 「数量」のパラメータ名の左に「<M code="e157"/>」のアイコンが表示されています。それをクリックするとメニューが表示されます。
2. メニューから「<M code="e322"/>変数の選択」を選び、使用したい変数を指定します。
3. 「<M code="e157"/>」がハイライトされ、数量に変数が設定されます。

このように、変数を使用することで、アイテムの増減量を動的に変更することができます。
</div>

**※RPG-Coboでは、イベントコマンドの色々なパラメータに変数や式を割り当てることが出来るため、非常に柔軟で動的なイベントの作成が可能です。**

#### <M code="ea50"/> 会話メッセージやUIに変数を内容を表示する

会話中のテキストに変数の値を埋め込むことができます。例えば、変数IDが`G000`のグローバル変数の値を表示したい場合は、以下のように記述します。

```
RPG-Coboへようこそ！
G000 の値は $G000 です。 ${G000} でも表示できます。
PTIME の値は $PTIME です。 ${PTIME + 1000} みたいに計算結果を表示することもできます。
```

### <M code="e8af"/> 変数の「型」
---

「変数」にはさまざまな型があります。主に数値型、文字列型、ブール(ON/OFF)型、さらには配列、テーブルなどがあり、それぞれの型に応じた値を保持することができます。  
注意が必要なのは、変数同士の型が一致していない場合、計算や比較が正しく行われないことがある点です。中には計算時にエラーが起きてしまう場合もあります。
どの変数にどの型の値が入っているのかを把握しておくことが重要です。

#### <M code="ea50"/> 比較の際のルール

- 左辺または右辺のどちらかがブール(ON/OFF)の場合は、対の値はブールに変換されます。  
  例えば、比較が `W = ON` となっている場合は、`W` は、0 であれば OFF、0 以外であれば ON として扱われます。

- `＜` `≦` `＞` `≧` のような比較演算子を使用する場合は、数値同士の比較は正しく行われますが、片方が数値でない場合は意図しない結果になることがあります。  
  文字列で "0" と入っていても数値としては認識されないので注意してください。
