イベントコマンドの「<M code="e0b7"/> メッセージ」は、「タグ」という構文によって、会話のテキストに装飾を加えることができ、さらにエフェクトや効果音、ボイスなども出すことが出来ます。  

### <M code="e8af"/> 右クリックメニューからタグを挿入
まずは簡単に、右クリックメニューからタグを挿入してみましょう。「<M code="e0b7"/> メッセージ」の編集画面で右クリックすると、タグ等を挿入するメニューが表示されます。
<SS src='docs/message-1.png' alt=''/>

|メニュー|説明|
|---|---|
|<M code="e545"/> 絵文字|絵文字やアイコン、ボタンアイコンを直接挿入します。|
|テキストスタイル|テキストを太字や斜めにするタグを挿入します。等角フォントにもできます（英数字のみ）。|
|フォントサイズ|テキストのフォントサイズを変更するタグを挿入します。|
|フォントカラー|テキストの色を変更するタグを挿入します。|
|文字送り|文字送りのタイミングや改行、改ページ、ウェイトなどを設定するタグを挿入します。|
|アクション|エフェクトを発生させたり、効果音やボイスを再生するタグを挿入します。|
|<M code="f120"/> 挿入 アイテム名 |データベースにあるアイテム名を挿入します。アイコン添えることもできます。|


### <M code="f10d"/> タグの構文
右クリックメニューからタグを挿入した場合に以下のようにテキストが挿入されると思います。例えば、テキストスタイル⇒ Bold を挿入すると以下のようになります。

```
こんにちは [B] 太い文字！
```

この`[B]`というのが太字にするタグで、直接テキストとして入力しても全く同じ効果になります。タグの入力に慣れると、右クリックメニューを使わずに直接タグを入力すると効率が良くなります。  
以下のように直接指定することで逆に直観的にテキストの装飾が行えるものもあります。

`[#fc0]` `[#ffcc00]` : 両方とも黄色の文字になります。cssなどでお馴染みのカラーコードを使用して文字が指定できます。
`[FX200]` : 「怒り」のエモーションエフェクトを発生させます。IDがFX200からはエモーションのエフェクトになっており、IDの対応を覚えておくと表情豊かな表現をすぐに指定することができます。

### <M code="f10d"/> タグリファレンス

キャラ演出ツールは、人型のキャラと同様に動く地形の動きも詳細につけることができます。  
一点だけ動く地形が人型のキャラと違うところは、移動アクションで位置と回転、イージング（動きに緩急をつけられる）など詳細につけることができるところです。

- *タグ内の`x`は0~9の整数が入ります。*

|メニュー|説明|
|---|---|
|`[b]`|太字にするタグです。|
|`[i]`|斜体にするタグです。|
|`[#xxx] [#xxxxxx]`|文字の色を変更するタグです。例: `[#ff0000]` は赤色になります。|
|`[+] [-] [+x] [-x]`|フォントサイズを変更するタグです。xは0~9の整数で、`[+]`は`[+3]`と同じ効果です。|
|`[fx]`|フォントを番号で指定します。`[f0]`:元フォント、`[f1]`:uiフォント、`[f2]`:等角英数1、`[f3]`:等角英数2、`[f4]`:アイコン|
|`[.]`|文字送りを停止してボタン入力を待つタグです。|
|`[p]`|改ページを行うタグです。|
|`[>] [<] [=]`|文字送り速度を変化させます。`[>]` は早く、`[<]` は遅く、`[=]` は通常の速度に戻します。|
|`[FXxxx]`|エフェクトを発生させるタグです。|
|`[SExxx]`|効果音を発生させるタグです。|
|`[VAxxx VOICEID]`|ボイスを再生するタグです。ボイスは指定が2つあり、`VAxxx` がボイスアクターID、`VOICEID` がアクター内のボイスIDです。`*`を指定したワイルドカード指定も可能です。|
