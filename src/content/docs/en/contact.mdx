## <M code="f083"/> Important Notes
Please read the following notes before contacting us.

- This page is not a support desk for RPG-Cobo products.
  We cannot answer questions about how to use the tool or about malfunctions.
- We do not reply individually to opinions or requests.
- We will reply by email, so please make sure you can receive email messages.

## <M code="e160"/> When Something Goes Wrong

- FAQ: First, check the "When something goes wrong" tab in the [FAQ](/faq).
- Documentation: See whether the "When you run into trouble" chapter in the documentation has a solution.
- Discord: Please report the issue in Discord's #help-ja (questions) or #bug-report-ja (bug reports) channel.
  *Before posting, please check whether someone else has already posted a solution.*
- GitHub: If you can help improve the issue, please report it on a GitHub issue.
