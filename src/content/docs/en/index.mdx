## <M code="e0e0"/> What is RPG-Cobo?

<Card2 title="A next-generation tool for RPG development" icon="pencil" img="top/rpgcobo1.png">
RPG-Cobo is a next-generation RPG development tool you can start using for free.  
High-resolution voxels, modern rendering technology, outstanding usability, and a wide range of advanced and unique features you have never seen before.

The one and only tool that turns your ideas into the best possible RPG experience is here.
</Card2>

<Card2 title="A map editor that makes it easy to create high-quality 3D maps" icon="pencil" rev={true} imgs={["feature/map1.png","feature/block1.png","feature/map2.png"]}>
- With the ease of assembling blocks, you can create 3D maps surprisingly easily.
- Thanks to highly expressive voxel assets, you can create attractive and original maps of your own using only the default assets included with the tool.
- Several hundred rich block assets, ranging from small to large, are included by default.
</Card2>

<Card2 title="Everything is under your control, with no programming required" icon="pencil" imgs={["feature/db1.png","feature/event1.png","feature/trans1.png","feature/build1.png"]}>
- Intuitively and visually edit all the data needed for an RPG, including party members, enemies, skills, and items.
- Control story progression, presentation, and all other game logic easily and without code through the event editor.
- Multilingual localization with AI translation is included by default. Share your RPG with the world!
- AI-powered expressive auto-generation is also supported for voice creation!
- Export to **web browsers, Windows, Android, and iOS**
</Card2>

<Card2 title="Unlimited possibilities with open source" icon="pencil" rev={true} img="top/opensource.png">
RPG-Cobo is an open-source RPG development tool. It is released for free on GitHub under the Apache 2 license, and all assets can be freely redistributed for both commercial and non-commercial use.  
It also supports extending both games and the tool itself through plugins, so you can expand them any way you like.
</Card2>
