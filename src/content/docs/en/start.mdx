Welcome to the RPG-Cobo guide!

This guide is for people using RPG-Cobo for the first time and explains how to learn the tool step by step.  
To keep things easy to understand, it avoids the finer details of the specifications and focuses on explaining everything as simply as possible.

<SS src='docs/start-1.png' alt=''/>

## <M code="f10d"/> What you can learn in this guide
The guide is organized into chapters. By reading them in order, you can learn how to operate RPG-Cobo and eventually master the complete workflow for making a simple RPG.

Here is a brief overview of what each chapter covers.

#### 1. Get ready
- How to download and install the tool
- How to create a project
- How to use the basic tool interface

#### 2. Maps
- How to create maps
- How to design maps in the map editor
- How to configure battles
- How to debug with test play
- Efficient map production with map assets

#### 3. Events
- How to place many different kinds of events
- How to build your own custom processing with custom events
- How to create elaborate presentations with the character effect tool

#### 4. Database
- An explanation of the database that stores various RPG data
- How to edit the main databases, such as players, enemies, items, and skills
- How to edit game-wide settings and rules

#### 5. Game assets (resources)
- How to edit major resources such as character voxels and enemy pictures
- How to create resources in external editors
- An introduction to other kinds of resources

#### 6. Distribute your game
- How to register as a user
- How to build and export your game for distribution
- Tips for distributing your game

#### 7. Use it even better
- A more in-depth look at features for users who already understand the basics of the tool

#### 8. Practical! Making an RPG in 30 minutes (in progress)
- A case study that walks through creating a small RPG step by step
- Build one map and create a full sequence of events: conversations, quest acceptance, battles, and quest completion
- Edit the necessary databases, including item creation and initial party setup
- Debug the finished game, build it, and distribute it
