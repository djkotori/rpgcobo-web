Event commands in an RPG development tool are an important feature for controlling game progression and presentation.
In RPG-Cobo, event commands can also be added and extended through plugins.  
This page explains in detail how to add event commands in RPG-Cobo plugin development.

### About the plugin explained on this page
---
We will explain the following two sample plugins.

1. work/plugin-samples/distancecmd.plugsk: Calculates the distance between the coordinates of two targets.
2. work/plugin-samples/randomcmds.plugsk: Randomly executes one command from within a child command list.


### 1: distancecmd.plugsk
---
This event command calculates the distance between two specified targets and stores it in a specified variable.  
It is a very standard example of an event command that defines `props` for property definitions, `cmdinfo` for command information, and `exec` for command execution.
*Note: `cmdinfo` can be omitted in this example.*

Let's first look at the sample plugin as-is (some comments are omitted).

```js
import PropertyType;
import RPGPropertyType;

pluginfo <- {
	name : { "ja":"距離取得","en":"Get Distance"}
	author : "djkotori"
	ver : "0.0.1"
	desc : { "ja":"距離を取得するイベントコマンドを追加します。","en":"Adds an event command to get the distance."}
	props : []
}

// Function called when the plugin loads. Here we add a new event command definition to RPGSystem.eventcmd.
function loadPlugin( args, opt){

	// Add the definition for the distance command
	local who2list = [
		{ lbl="$T.who_player", val=1 }
		{ lbl="$T.who_event", val=2 }
	];

	RPGSystem.eventcmd .. {
		category = 1							// Variable category. It belongs to the same category as variable settings and array processing.
			key = "excmd_distance"					// *The same key must not already exist in event commands.
			name = { "ja":"距離取得","en":"Get Distance"}
		tips = { "ja":"2つの対象間の距離を取得します。","en":"Get the distance between two targets."}
		icon = "\ue41c"
		color = (0xFF9326ff, 0xFFB973ff)
		props = [
			{ pid="from", lbl="$T.lbl_target 1", type=LIST, list=who2list, variable=1, }
			{ pid="to", lbl="$T.lbl_target 2", type=LIST, list=who2list, variable=1, }
			{ pid="retvar", lbl="$T.cmd_macro_retvar", type=VARIABLE, varbits=1|2, constbits=0 },
		]
		defval = { from=1, to=2, retvar="W" }
		// Function that returns the information displayed in the tool's command list
		cmdinfo = @( cmd){
			local info = sprintf( "%S ～ %S => %S", propstr( props, cmd, "from"), propstr( props, cmd, "to"), propstr( props, cmd, "retvar"));
			return { info = info, };
		}
		// Function that executes this command
		exec = @( runner, cmd){
			local t0 = runner.getWho3D( cmd.from), t1 = runner.getWho3D( cmd.to);	// Get the 3D object for each target.
			local dist = t0.pos.hypot( t1.pos);		// Calculate the distance. hypot returns the distance between two vectors.
			runner[cmd.retvar] = dist;	// Store the return value in the specified variable
		}
	}
	return true;
}
```

#### Executing event commands

The `exec = @( runner, cmd)` function is called when the event command is executed.
`runner` is an instance of the RPGEventRunner class that executes the event command. You can access the game state and variables through `runner`.  
`cmd` is a table that stores the property values configured in the plugin manager based on the event command definition. By referencing properties such as `cmd.from` and `cmd.to`,
you can obtain the values set by the user.

- Inside the command's `exec` function, first use `runner.getWho3D( cmd.from)` and `runner.getWho3D( cmd.to)` to obtain the 3D objects for the two specified targets.
- Then use `t0.pos.hypot( t1.pos)` to calculate the distance between the position vectors of the two 3D objects. `hypot` is a Vector3D class function that returns the distance between two vectors.
- Finally, store the calculated distance in the specified variable with something like `runner[cmd.retvar] = dist`. This lets the user obtain the distance as the result of the event command.

From the `runner` object, you can directly access work variables `W, X, Y, Z`, event variables `A, B, C, D`, and other variables.


### 2: randomcmds.plugsk
---
This event command randomly executes one command from within its child command list.  
What makes this command special is that, just like conditional branches and loops, it has a child command list.
Then it randomly executes one command from that child list, and the other commands are not executed.

Let's first look at the sample plugin as-is (some comments are omitted).

```js
pluginfo <- {
	name : { "ja":"ランダムコマンド","en":"Random Command"}
	author : "djkotori"
	ver : "0.0.1"
	desc : { "ja":"このコマンド以下のどれか一つのコマンドを実行","en":"Execute one of the following commands."}
	props : []
}

// Function called when the plugin loads. Here we add a new event command definition to RPGSystem.eventcmd.
function loadPlugin( args, opt){
	RPGSystem.eventcmd .. {
		category = 0							// Basic category. It belongs to the same category as conditional branches and loops.
			key = "excmd_randomcmd"					// *The same key must not already exist in event commands.
			name = { "ja":"ランダムコマンド","en":"Random Command"}
		tips = { "ja":"中にあるコマンドのいずれか1つをランダムで実行します。","en":"Randomly executes one of the commands inside."}
		icon = "\ue043"
		color = (0x00A3D9ff, 0x73DCFFff)
		props = []								// No parameters for this command. Only the child command block.
			defval = { cmdblocks = [[]] }			// cmdblocks is an array of child command blocks. Here we store one empty block as the default value.
		
		// Expand this command into program code.
		// For details, see RPGEventCompiler.parsecmd( cmd). Here it generates the code that will be executed when the command runs.
		parsecode = @( cmd){
			local n = length( cmd["cmdblocks"][0]);
			push( "{ local rndi = rnd( %d);" % n).indent( 1).lf(); 
			foreach( i, cb in cmd["cmdblocks"][0]){
				push( "if( rndi==%d)" % i); parseblock( [cb], false);
			}
			indent( -1).push( "}").lf();
		}
	}
	return true;
}
```

#### Expanding an event command list into program code

This event command can have a child command list because the following line is present in the command definition.

```js
defval = { cmdblocks = [[]] }
```

The next line generates the code that is called when the command runs.
```js
parsecode = @( cmd){
	...
}
```

RPG-Cobo's event commands are turned by the RPGEventCompiler class into executable sk script from the saved event command list.  
As a result of this parsecode, the following code is generated. That is how the mechanism for randomly executing one command works.
```js
{
	local rndi = rnd( 3);	// Generate an integer from 0 to 2 using the random function
	if( rndi==0){
	// Code to execute the 0th command in the child command list is expanded here
	}
	if( rndi==1){
	// Code to execute the 1st command in the child command list is expanded here
	}
	if( rndi==2){
	// Code to execute the 2nd command in the child command list is expanded here
	}
}
```
