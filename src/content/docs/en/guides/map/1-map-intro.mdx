Come on, let's start making the most enjoyable part of RPG development: maps!
The map editor is the editor with the most features concentrated into RPG-Cobo, and for that reason it can also be the most difficult tool. Take your time and learn its operations little by little.

First, select "<M code="f11e"/> Map" from the activity bar on the left. The following side menu appears.

<div class="sspart">
<SS src='docs/map-intro-1.png' alt=''/>

##### <M part="A"/> Map group list
Map groups are used to organize the many maps you create.  

- "<M code="e866"/> Template" is a special group. Maps placed in this group can be selected in the "Template selection" of the "Create new map" dialog.

##### <M part="B"/> Map list
Maps belonging to the selected map group are displayed in a list together with thumbnails of the overall map.  
From the right-click context menu, you can move groups, change IDs, duplicate maps, and more.
</div>

### <M code="f10d"/> Open a map
Let's open "**M001 First Map**" from the "<M code="f11e"/> Map" side menu. A screen like the one below appears. This is the map editor.

<div class="sspart">
<SS src='docs/map-intro-2.png' alt=''/>

##### <M part="A"/> Map canvas
The map editor canvas is displayed in 3D, and you can freely change the viewpoint with the mouse or a laptop trackpad.


##### <M part="B"/> Top toolbar
Contains tools for switching display methods and showing information.

- <M code="e569"/> : Show cursor coordinates
- <M code="ebca"/> : Toggle collision display
- <M code="e3ec"/> : Toggle grid display over blocks
- <M code="e40b"/> : Toggle weather and background display
- <M code="e883"/> : Toggle preview of back-face culling in map settings
- <M code="e88e"/> : Toggle display of information such as polygon count
- Render settings menu: Switch rendering settings such as time of day and location.

##### <M part="C"/> Toolbar
A toolbar with tools for creating maps. More on that later.

##### <M part="D"/> Tool panel
Various settings are shown for the selected tool.
</div>

### <M code="f10d"/> Create a new map

Click the "<M code="e5d2"/>" button at the top right of the "<M code="f11e"/> Map" side menu and choose "⊕ New map" to show the new map dialog.

<SS src='docs/map-intro-3.png' alt=''/>

The new map creation dialog appears.  
After entering the necessary information, press the "Confirm" button.

<div class="sspart">
<SS src='docs/map-intro-4.png' alt=''/>

##### <M part="A"/> Map ID
Each map gets an ID from M000 to M999. Here you choose the ID to assign to the new map. *The default available IDs are already assigned.*

##### <M part="B"/> Map group
You can specify a map group for organizing maps. Map groups can be moved freely later.

##### <M part="C"/> Template selection
Choose the template that is closest to the map you want to make.
</div>
