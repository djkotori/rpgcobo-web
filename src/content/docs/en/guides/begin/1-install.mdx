### <M code="f10d"/> RPG-Cobo system requirements
Before using RPG-Cobo, please make sure your computer meets the system requirements.<br/>
**Note: In general, it should work without issue on any PC that can run Windows 11.**

|  |Minimum system requirements|Recommended system requirements|
|--|-----------|-----------|
|OS|Microsoft® Windows 10 (64-bit)| |
|CPU|4-core Intel or AMD or better|Intel Core i5-8250U / AMD Ryzen 3 7530|
|Memory|8 GB|16 GB|
|GPU|OpenGL 4.2 or later|NVIDIA GeForce 1050 / AMD Radeon Vega 6|
|Display size|1920x1080| |
|Internet|Required||

<Steps>
