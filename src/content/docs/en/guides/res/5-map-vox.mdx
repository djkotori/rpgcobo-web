Map voxels define everything about the blocks that make up a map: their design, color scheme, collision, and more.


Open "<M code="f089"/> Resources" from the activity bar and then "<M code="f11d"/> Map voxels."

<div class="sspart">
<SS src='docs/map-vox-1.png' alt=''/>

##### <M part="A"/> Block category selection
The character models are shown in a list. You can rotate the display by dragging with the right mouse button.  
As a common operation in the resource editor, you can "copy," "paste," and "sort by drag and drop" for list items.

##### <M part="B"/> Resource list
Displays the blocks in the selected block category as a list.

##### <M part="C"/> Properties
The settings vary greatly depending on the block category. What they all share are the voxel model assignment and the palette.

##### <M part="D"/> Preview
You can preview the model and collision.
</div>

### <M code="f10d"/> Edit collision
You can freely set the collision shape for blocks such as "Door," "Lamp," "Exterior," and "Interior." Press the "Collision" button in the properties to open the collision editor dialog.

<div class="sspart">
<SS src='docs/map-vox-2.png' alt=''/>

##### <M part="A"/> Size and alignment
You can specify the size and alignment method so the model is positioned neatly.

##### <M part="B"/> Pen selection
Choose from "<M code="e909"/> Erase," "<M code="e146"/> Place," and "<M code="e3ae"/> Replace."

##### <M part="C"/> Collision shape selection
Choose a shape that fits the model well and does not cause the player to get stuck.  
**Rotate using the "<M code="e166"/><M code="e166"/>" button on the right.**

##### <M part="D"/> 3D canvas
Left-click to place/remove collisions.
</div>

### <M code="f10d"/> Design map voxels
Like character voxels, map voxels can be edited directly from the context menu with "<M code="e745"/> Edit voxel."

After editing and updating the file, choose "<M code="f053"/> Reload RPG-Cobo (Ctrl+F4)" from the file menu to reflect the changes.

<Aside type="caution">
Some blocks such as doors and roofs are made with structures based on program rules.
If editing the vox file breaks this structure, the block may no longer work correctly, and in the worst case the tool may fail to launch.

Always make a "<M code="e623"/> project backup" before editing map voxels.
</Aside>
