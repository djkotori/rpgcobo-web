Resources are the materials used in a game, such as graphics and sound.  
RPG-Cobo provides rich features so that both creators who want to build resources from scratch and hobby users who only want to tweak them a little can easily make their own materials and add character to them.

First, select "<M code="f089"/> Resources" from the activity bar. A list of the resource types that can be edited in RPG-Cobo will appear.

### <M code="f10d"/> By the way, what is voxel?
In RPG-Cobo, all major 3D models are made in a format called "voxel," but many people may not be familiar with the term.  
A voxel is like 3D pixel art, created by extending pixel art directly into 3D.
Compared with the mainstream polygon approach, it has the disadvantage that free-form shapes are harder to make, but the biggest benefit is that **you can create 3D models with the same ease as drawing pixel art**.
