Welcome to the RPG-Cobo guide!

This guide is for people using RPG-Cobo for the first time to learn how to use the tool.  
To keep the explanations easy to understand, we will avoid going into detailed specifications and keep things as simple as possible.

<SS src='docs/start-1.png' alt=''/>

## <M code="f10d"/> What you can learn in this guide
This guide is organized into chapters. By reading them in order, you can learn how to operate RPG-Cobo, and by the end you will have mastered the general procedure for creating a simple RPG.

Here is a brief introduction to what you can learn in each chapter.

#### 1. Getting ready
- How to download and install
- How to create a project
- How to use the tool's basic screens

#### 2. Maps
- How to create maps
- How to design maps in the map editor
- How to set up battles
- How to debug (test play)
- Efficient map creation using map assets

#### 3. Events
- How to place various kinds of events
- How to build your own logic with custom events
- How to create elaborate presentations with the character presentation tool

#### 4. Database
- An explanation of the database that holds the various kinds of RPG data
- How to edit the main databases such as players, enemies, items, and skills
- How to edit game-wide settings and rules

#### 5. Game assets (resources)
- How to edit major resources such as character voxels and enemy pictures
- How to create resources in external editors
- An introduction to various other resources

#### 6. Distributing your game
- How to register as a user
- How to build and export for distribution
- Know-how for distributing your game

#### 7. Mastering more features
- For those who have learned the tool's features in broad strokes, explanations of more advanced features.

#### 8. Hands-on! Making an RPG in 30 minutes (in preparation)
- A case study that walks through creating a small RPG step by step
- Creating a map and, within it, a series of events from having a conversation, receiving a quest, battling, to completing the quest
- Editing the necessary databases, such as creating items and setting up the initial party
- Debugging the finished game, building it, and distributing it
