## Math functions

The math functions are stored in the `Math` table.

### Constants

```javascript
Math.PI      // pi (about 3.14159)
Math.DTOR    // degrees to radians conversion factor (PI / 180)
Math.RTOD    // radians to degrees conversion factor (180 / PI)
Math.PI2     // pi times 2
Math.HPI     // pi divided by 2
```

### Basic math functions

#### `Math.abs(value)`
Returns the absolute value.

**Arguments**:
- `value` (int/float): input value

**Return value**: absolute value

#### `Math.sqrt(value)`
Returns the square root.

**Arguments**:
- `value` (float): input value

**Return value**: square root

#### `Math.saturate(value)`
Clamps a value to the range 0 to 1.

**Arguments**:
- `value` (float): input value

**Return value**: value clamped to the range 0 to 1

#### `Math.sign(value)`
Returns the sign (-1, 0, 1).

**Arguments**:
- `value` (int/float): input value

**Return value**: -1 (negative), 0 (zero), 1 (positive)

### Trigonometric functions

#### `Math.sin(rad)`, `Math.cos(rad)`, `Math.tan(rad)`
Trigonometric functions.

**Arguments**:
- `rad` (float): radians

**Return value**: value of the trigonometric function

#### `Math.asin(value)`, `Math.acos(value)`, `Math.atan(value)`
Inverse trigonometric functions.

**Arguments**:
- `value` (float): input value

**Return value**: radians

**Description**: `asin` and `acos` automatically clamp out-of-range values (-1 to 1).

#### `Math.atan2(y, x)`
Two-argument arctangent.

**Arguments**:
- `y` (float): Y component
- `x` (float): X component

**Return value**: radians (-π to π)

### Logarithmic and exponential functions

#### `Math.log(value)`, `Math.log2(value)`, `Math.log10(value)`
Logarithmic functions (natural log, base 2, base 10).

**Arguments**:
- `value` (float): input value

**Return value**: logarithmic value

#### `Math.logn(value, base)`
Logarithm with an arbitrary base.

**Arguments**:
- `value` (float): input value
- `base` (float): base

**Return value**: logarithmic value

#### `Math.exp(value)`, `Math.exp2(value)`
Exponential functions (e^x, 2^x).

**Arguments**:
- `value` (float): exponent

**Return value**: exponential value

#### `Math.pow(base, exp)`
Power calculation.

**Arguments**:
- `base` (float): base
- `exp` (float): exponent

**Return value**: base^exp

### Rounding functions

#### `Math.floor(value)`, `Math.ceil(value)`, `Math.round(value)`
Rounding functions (floor, ceiling, round).

**Arguments**:
- `value` (float): input value

**Return value**: rounded float value

#### `Math.ifloor(value)`, `Math.iceil(value)`, `Math.iround(value)`
Rounds as an integer.

**Arguments**:
- `value` (float): input value

**Return value**: rounded int value

#### `Math.floor2(value)`
Rounds down to a power of two.

**Arguments**:
- `value` (float): input value

**Return value**: value rounded down to a power of two

### Maximum, minimum, and range

#### `Math.max(value1, value2, ...)`
Returns the maximum value (variable-length arguments).

**Arguments**:
- `value1, value2, ...` (int/float): values to compare

**Return value**: maximum value

#### `Math.min(value1, value2, ...)`
Returns the minimum value (variable-length arguments).

**Arguments**:
- `value1, value2, ...` (int/float): values to compare

**Return value**: minimum value

#### `Math.clamp(value, min, max)`
Clamps a value to a specified range.

**Arguments**:
- `value` (int/float): input value
- `min` (int/float): minimum value
- `max` (int/float): maximum value

**Return value**: clamped value

### Interpolation

#### `Math.lerp(a, b, t)`
Linear interpolation.

**Arguments**:
- `a` (float): start value
- `b` (float): end value
- `t` (float): interpolation factor (0 to 1)

**Return value**: interpolated value (a + (b-a)*t)

#### `Math.lerpcolor(color1, color2, t)`
Linear interpolation of colors.

**Arguments**:
- `color1` (int): start color (RGBA format)
- `color2` (int): end color (RGBA format)
- `t` (float): interpolation factor (0 to 1)

**Return value**: interpolated color (int)

### Bit operations

#### `Math.shift(value, shift)`
Bit shift.

**Arguments**:
- `value` (int): value
- `shift` (int): shift amount (positive: left shift, negative: right shift)

**Return value**: shifted value

#### `Math.bitcount(value)`
Returns the number of set bits.

**Arguments**:
- `value` (int): value

**Return value**: number of bits set to 1

#### `Math.pot(value)`
Returns the next power of two.

**Arguments**:
- `value` (int): input value

**Return value**: smallest power of two greater than or equal to value

#### `Math.msb(value)`
Returns the position of the most significant bit.

**Arguments**:
- `value` (int): value

**Return value**: index of the most significant bit

#### `Math.lsb(value)`
Returns the position of the least significant bit.

**Arguments**:
- `value` (int): value

**Return value**: index of the least significant bit

### Other

#### `Math.mod2(value, min, max)`
A modulo that loops within a range.

**Arguments**:
- `value` (float): value
- `min` (float): minimum value
- `max` (float): maximum value

**Return value**: value looped within the range min to max

#### `Math.digit(value, precision)`
Rounds to the specified precision.

**Arguments**:
- `value` (float): value
- `precision` (int): precision

**Return value**: rounded value

#### `Math.vtohp(x, y, z)` / `Math.vtohp(vector)` / `Math.vtohp(array)`
Calculates the heading and pitch angles from a vector.

**Arguments**:
- `x, y, z` (float): vector components
- or `vector` (Vector3D): vector
- or `array` (array): an `[x, y, z]` array

**Return value**: a `[heading, pitch]` tuple (radians)

#### `Math.length(...values)`
Calculates a length from multiple values.

**Arguments**:
- `...values` (float): values of each component

**Return value**: `sqrt(sum(values))`

## Classes

### Random

Pseudo-random number generator (Xorshift).

#### Constructor

```javascript
Random([seed[, warmup]])
```

**Arguments**:
- `seed` (int, optional): seed value (current time if omitted)
- `warmup` (int, optional): number of warmup iterations

#### Fields

- `x`, `y`, `z`, `w` (int): internal state (read-only)

#### Methods

##### `setSeed(seed[, warmup])`
Sets the seed value.

**Arguments**:
- `seed` (int): seed value
- `warmup` (int, optional): number of warmup iterations

##### `next([bits])`
Generates random bits.

**Arguments**:
- `bits` (int, optional): number of bits (default: 24)

**Return value**: random integer

##### `nexti([min,] max)`
Generates a random value in an integer range.

**Arguments**:
- `min` (int, optional): minimum value (default: 0)
- `max` (int): maximum value (**exclusive**)

**Return value**: random integer greater than or equal to min and less than max

##### `nextf([min,] max)`
Generates a random value in a floating-point range.

**Arguments**:
- `min` (float, optional): minimum value (default: 0.0)
- `max` (float, optional): maximum value (default: 1.0)

**Return value**: random float greater than or equal to min and less than max

##### `crypt(buffer[, length])`
XOR-encrypts a buffer with random numbers.

**Arguments**:
- `buffer` (ByteBuffer): buffer to encrypt
- `length` (int, optional): length to encrypt

##### `choose(value1, value2, ...)`
Randomly picks one of the arguments.

**Arguments**:
- `value1, value2, ...`: choices

**Return value**: randomly chosen value

##### `choosea(array)`
Randomly picks one element from an array.

**Arguments**:
- `array` (array): array

**Return value**: randomly chosen element

#### Call operator

```javascript
rnd(max)              // 0 to max
rnd(min, max)         // min to max
```

**Description**: Calls `nexti` or `nextf` (automatically determined based on the argument types).

### Vector3D

3D vector class.

#### Constructor

```javascript
Vector3D()                          // (0, 0, 0)
Vector3D(value)                     // (value, value, value)
Vector3D(x, y)                      // (x, y, 0)
Vector3D(x, y, z)                   // (x, y, z)
Vector3D(vector)                    // copy
Vector3D([x, y, z])                 // from an array
```

#### Fields

- `x`, `y`, `z` (float): components
- `[0]`, `[1]`, `[2]` (float): index access (aliases)

#### Methods

##### Setting and getting

##### `set(x, y, z)` / `set(value)` / `set(vector)` / `set([x,y,z])`
Sets the values.

**Return value**: itself

##### `iszero()`
Determines whether this is a zero vector.

**Return value**: `true` if all components are 0

##### `equals(other)`
Determines whether this equals another vector.

**Arguments**:
- `other` (Vector3D): comparison target

**Return value**: `true` if equal

##### Arithmetic operations

##### `add(x, y, z)` / `add(value)` / `add(vector)`
Performs addition.

**Return value**: itself

##### `sub(x, y, z)` / `sub(value)` / `sub(vector)`
Performs subtraction.

**Return value**: itself

##### `mul(x, y, z)` / `mul(value)` / `mul(vector)`
Performs multiplication.

**Return value**: itself

##### `div(x, y, z)` / `div(value)` / `div(vector)`
Performs division.

**Return value**: itself

##### `scale(x, y, z)` / `scale(value)` / `scale(vector)`
Scale (alias for multiplication).

**Return value**: itself

##### Vector operations

##### `length()`
Returns the length of the vector.

**Return value**: `sqrt(x*x + y*y + z*z)`

##### `lengthSq()`
Returns the squared length of the vector.

**Return value**: `x*x + y*y + z*z`

##### `normalize()`
Normalizes the vector (makes its length 1).

**Return value**: itself

##### `dot(other)`
Calculates the dot product.

**Arguments**:
- `other` (Vector3D): another vector

**Return value**: dot product value

##### `cross(other[, result])`
Calculates the cross product.

**Arguments**:
- `other` (Vector3D): another vector
- `result` (Vector3D, optional): where to store the result

**Return value**: cross product vector (new or `result`)

##### `hypot(other)`
Returns the distance between two vectors.

**Arguments**:
- `other` (Vector3D): another vector

**Return value**: distance

##### `hypotSq(other)`
Returns the squared distance between two vectors.

**Arguments**:
- `other` (Vector3D): another vector

**Return value**: squared distance

##### Transforms

##### `transform(matrix)`
Transforms by a matrix (including translation).

**Arguments**:
- `matrix` (Matrix): transform matrix

**Return value**: itself

##### `transform0(matrix)`
Transforms by a matrix (without translation).

**Arguments**:
- `matrix` (Matrix): transform matrix

**Return value**: itself

##### `transformw(matrix)`
Transforms by a matrix and returns the w component.

**Arguments**:
- `matrix` (Matrix): transform matrix

**Return value**: w component (float)

##### `rotate(quaternion)` / `rotate(h, p, b)` / `rotate(vector)`
Applies a rotation.

**Arguments**:
- `quaternion` (Quaternion): rotation quaternion
- or `h, p, b` (float): heading, pitch, bank (radians)
- or `vector` (Vector3D): rotation vector

**Return value**: itself

##### Other

##### `saturate()`
Clamps each component to the range 0 to 1.

**Return value**: itself

##### `floor()`, `ceil()`, `round()`
Rounds each component.

**Return value**: itself

##### `lerp(other, t[, result])`
Performs linear interpolation.

**Arguments**:
- `other` (Vector3D): end vector
- `t` (float): interpolation factor (0 to 1)
- `result` (Vector3D, optional): where to store the result

**Return value**: interpolated vector

##### `min(other)`, `max(other)`
Takes the minimum or maximum of each component.

**Arguments**:
- `other` (Vector3D): another vector

**Return value**: itself

##### `hasNaN()`
Checks whether the vector contains NaN.

**Return value**: `true` if it contains NaN

##### `nanCheck()`
Returns NaN/Inf information as a bitfield.

**Return value**: bitfield (int)

#### Static methods

##### `Vector3D.fromRandom(min, max)`
Generates a random vector.

**Arguments**:
- `min` (float): minimum value of each component
- `max` (float): maximum value of each component

**Return value**: random vector

#### Operators

```javascript
v1 + v2          // addition (new vector)
v1 - v2          // subtraction (new vector)
v1 * v2          // multiplication (new vector)
v1 / v2          // division (new vector)
v1 % v2          // modulo (new vector)
v1 << v2         // assignment (v1 = v2)
-v               // negation (new vector)
v1 | v2          // dot product (float)
v1 ^ v2          // cross product (new vector)
v(x, y, z)       // set via call operator
```

### Quaternion

Quaternion (rotation) class.

#### Constructor

```javascript
Quaternion()                              // identity quaternion
Quaternion(x, y, z, w)                    // direct specification
Quaternion(angle, axis)                   // rotation around an axis
Quaternion(quaternion)                    // copy
Quaternion(matrix)                        // from a matrix
Quaternion([x, y, z, w])                  // from an array
```

#### Fields

- `x`, `y`, `z`, `w` (float): components
- `[0]`, `[1]`, `[2]`, `[3]` (float): index access

#### Methods

##### `set(x, y, z, w)` / `set(angle, axis)` / `set(other)`
Sets the values.

**Return value**: itself

##### `iszero()`
Determines whether this is an identity quaternion.

**Return value**: `true` if identity quaternion (w=1, x=y=z=0)

##### `equals(other)`
Determines whether this equals another quaternion.

**Arguments**:
- `other` (Quaternion): comparison target

**Return value**: `true` if equal

##### `norm()`
Returns the norm (length).

**Return value**: norm

##### `normalize()`
Normalizes the quaternion.

**Return value**: itself

##### `toMatrix()`
Converts to a 3x3 matrix.

**Return value**: `Matrix` object

##### `lerp(other, t[, result])`, `slerp(other, t[, result])`
Performs linear interpolation or spherical linear interpolation.

**Arguments**:
- `other` (Quaternion): end quaternion
- `t` (float): interpolation factor (0 to 1)
- `result` (Quaternion, optional): where to store the result

**Return value**: interpolated quaternion

##### `synthesize(other)`
Composes quaternions (multiplication).

**Arguments**:
- `other` (Quaternion): quaternion to compose

**Return value**: itself

##### `getHPB([result])`
Gets the Heading-Pitch-Bank angles.

**Arguments**:
- `result` (Vector3D, optional): where to store the result

**Return value**: `Vector3D(h, p, b)`

##### `setHPB(h, p, b)` / `setHPB(vector)`
Sets from Heading-Pitch-Bank angles.

**Arguments**:
- `h, p, b` (float): Heading, Pitch, Bank (radians)
- or `vector` (Vector3D): HPB vector

**Return value**: itself

##### `setAxis(angle, x, y, z)`
Sets a rotation around an axis.

**Arguments**:
- `angle` (float): rotation angle (radians)
- `x, y, z` (float): rotation axis

#### Static methods

##### `Quaternion.fromAxis(angle, axis)`
Creates a rotation quaternion around an axis.

**Arguments**:
- `angle` (float): rotation angle (radians)
- `axis` (Vector3D): rotation axis

**Return value**: `Quaternion` object

##### `Quaternion.from2Axis(from, to)`
Creates a rotation between two vectors.

**Arguments**:
- `from` (Vector3D): start vector
- `to` (Vector3D): end vector

**Return value**: `Quaternion` object

##### `Quaternion.fromHPB(h, p, b)` / `Quaternion.fromHPB(vector)` / `Quaternion.fromHPB([h,p,b])`
Creates a quaternion from HPB angles.

**Arguments**:
- `h, p, b` (float): Heading, Pitch, Bank
- or `vector` (Vector3D)
- or `[h, p, b]` (array)

**Return value**: `Quaternion` object

#### Operators

```javascript
q1 * q2          // composition (new quaternion)
q * v            // vector rotation (new vector)
q1 << q2         // assignment (q1 = q2)
-q               // conjugate (new quaternion)
q(...)           // set via call operator
```

### Plane

Plane class (ax + by + cz + d = 0).

#### Constructor

```javascript
Plane()                        // (0, 0, 0, 1)
Plane(a, b, c, d)              // direct specification
Plane(plane)                   // copy
Plane([a, b, c, d])            // from an array
```

#### Fields

- `a`, `b`, `c`, `d` (float): plane coefficients
- `[0]`, `[1]`, `[2]`, `[3]` (float): index access

#### Methods

##### `set(a, b, c, d)` / `set(plane)`
Sets the values.

**Return value**: itself

##### `equals(other)`
Determines whether this equals another plane.

**Arguments**:
- `other` (Plane): comparison target

**Return value**: `true` if equal

##### `normalize()`
Normalizes the plane (makes the normal vector length 1).

**Return value**: itself

##### `lerp(other, t)`
Performs linear interpolation.

**Arguments**:
- `other` (Plane): end plane
- `t` (float): interpolation factor

**Return value**: new `Plane` object

##### `setParam(nx, ny, nz, px, py, pz)` / `setParam(normal, position)`
Sets from a normal and a position.

**Arguments**:
- `nx, ny, nz` (float): normal vector
- `px, py, pz` (float): position on the plane
- or `normal`, `position` (Vector3D)

**Return value**: itself

##### `getHeight(x, y, z)` / `getHeight(position)`
Returns the height of the specified point from the plane.

**Arguments**:
- `x, y, z` (float): position
- or `position` (Vector3D)

**Return value**: height (float, signed distance)

##### `inside(x, y, z)` / `inside(vector)` / `inside(rect3d)`
Determines whether the specified object is inside the plane.

**Arguments**:
- `x, y, z` (float): position
- or `vector` (Vector3D)
- or `rect3d` (Rect3D)

**Return value**: `true` if inside

##### `project(position, direction)`
Calculates the projection point onto the plane.

**Arguments**:
- `position` (Vector3D): start position
- `direction` (Vector3D): direction vector

**Return value**: projection point (`Vector3D`)

##### `getIntersectTime(position, direction)`
Calculates the time to the intersection point with the plane.

**Arguments**:
- `position` (Vector3D): start position
- `direction` (Vector3D): direction vector

**Return value**: time to the intersection point (float), or a negative value if there is no intersection

##### `dot(vector)`
Calculates the dot product with the normal vector.

**Arguments**:
- `vector` (Vector3D): vector

**Return value**: dot product value

##### `transform(matrix)`
Transforms by a matrix.

**Arguments**:
- `matrix` (Matrix): transform matrix

**Return value**: itself

#### Operators

```javascript
p1 << p2         // assignment (p1 = p2)
p(...)           // set via call operator
```

### Matrix

4x4 matrix class.

#### Constructor

```javascript
Matrix()                                   // identity matrix
Matrix(e0, e1, ..., e15)                   // direct specification of 16 elements
Matrix(matrix)                             // copy
```

#### Fields

- `[0]` to `[15]` (float): matrix elements (column-major)

**Description**: Matrix elements are stored in column-major order.

```
[0  4  8  12]
[1  5  9  13]
[2  6  10 14]
[3  7  11 15]
```

#### Methods

##### Basic operations

##### `set(e0, ..., e15)` / `set(matrix)`
Sets the values.

**Return value**: itself

##### `identity()`
Sets to the identity matrix.

**Return value**: itself

##### `abs()`
Returns the absolute value of the matrix (the sum of the absolute values of each element).

**Return value**: float value

##### Matrix operations

##### `mult33(other[, result])`, `mult34(other[, result])`, `mult44(other[, result])`
Matrix multiplication (3x3, 3x4, 4x4).

**Arguments**:
- `other` (Matrix): matrix to multiply by
- `result` (Matrix, optional): where to store the result

**Return value**: result matrix (new or `result`)

##### `invert34([result])`, `invert34u([result])`, `invert44([result])`
Calculates the inverse matrix.

**Description**:
- `invert34`: 3x4 inverse matrix
- `invert34u`: 3x4 inverse matrix (uniform scale only)
- `invert44`: 4x4 inverse matrix

**Arguments**:
- `result` (Matrix, optional): where to store the result

**Return value**: inverse matrix

##### `transpose33([result])`, `transpose44([result])`
Calculates the transposed matrix.

**Arguments**:
- `result` (Matrix, optional): where to store the result

**Return value**: transposed matrix

##### Transform operations

##### `translate(x, y, z)`, `translate(vector)`
Applies a translation.

**Arguments**:
- `x, y, z` (float): translation amounts
- or `vector` (Vector3D/Rect3D)

**Return value**: itself

##### `ltranslate(x, y, z)`, `ltranslate(vector)`
Applies a translation in the local coordinate system.

**Arguments**: same as `translate`

**Return value**: itself

##### `scale(x, y, z)`, `scale(vector)`, `scale(value)`
Applies a scale.

**Arguments**:
- `x, y, z` (float): scale factors
- or `vector` (Vector3D)
- or `value` (float): uniform scale

**Return value**: itself

##### `lscale(x, y, z)`, `lscale(vector)`
Applies a scale in the local coordinate system.

**Arguments**: same as `scale`

**Return value**: itself

##### `rotate(quaternion)` / `rotate(h, p, b)` / `rotate(vector)` / `rotate([h,p,b])`
Applies a rotation.

**Arguments**:
- `quaternion` (Quaternion): rotation quaternion
- or `h, p, b` (float): Heading-Pitch-Bank
- or `vector` (Vector3D): HPB vector
- or `[h, p, b]` (array)

**Return value**: itself

##### Getting and setting elements

##### `setTranslation(x, y, z)` / `setTranslation(vector)`
Sets the translation component.

**Arguments**:
- `x, y, z` (float): position
- or `vector` (Vector3D/Rect3D)

**Return value**: itself

##### `getTranslation([result])`
Gets the translation component.

**Arguments**:
- `result` (Vector3D, optional): where to store the result

**Return value**: position vector (`Vector3D`)

##### `getRotation([result])`
Gets the rotation component.

**Arguments**:
- `result` (Quaternion, optional): where to store the result

**Return value**: rotation quaternion (`Quaternion`)

##### `getHPB([result])`
Gets the Heading-Pitch-Bank angles.

**Arguments**:
- `result` (Vector3D, optional): where to store the result

**Return value**: HPB vector (`Vector3D`)

##### `getScale([result])`
Gets the scale component.

**Arguments**:
- `result` (Vector3D, optional): where to store the result

**Return value**: scale vector (`Vector3D`)

##### `getAverageScale([result])`
Gets the average scale value.

**Arguments**:
- `result` (Vector3D, optional): where to store the result

**Return value**: uniform scale vector (`Vector3D(s,s,s)`)

##### Transform-related

##### `setSRT(t, s, r)`
Sets from a Transform (position, scale, rotation).

**Arguments**:
- `t` (Vector3D): position
- `s` (Vector3D): scale
- `r` (Quaternion): rotation

**Return value**: itself

##### `setTransform(transform[, pivot])`
Sets from a Transform object.

**Arguments**:
- `transform` (Transform): Transform object
- `pivot` (Vector3D, optional): pivot position

**Return value**: itself

##### `getTransform([result])`
Gets a Transform object.

**Arguments**:
- `result` (Transform, optional): where to store the result

**Return value**: `Transform` object

##### Other

##### `normalize()`
Normalizes the rotation component.

**Return value**: itself

##### `lerp(other, t[, result])`
Performs linear interpolation.

**Arguments**:
- `other` (Matrix): end matrix
- `t` (float): interpolation factor
- `result` (Matrix, optional): where to store the result

**Return value**: interpolated matrix

##### `integrate(array|...transforms)`
Integrates multiple Transforms or Matrices.

**Arguments**:
- `array` (array): array of Transforms or Matrices
- or `...transforms`: variable-length arguments

**Return value**: itself

##### `nanCheck()`
Returns NaN/Inf information as a bitfield.

**Return value**: bitfield (int)

##### `print([with4thRow])`
Outputs the matrix to the console.

**Arguments**:
- `with4thRow` (bool, optional): whether to also display the 4th row

#### Static methods

##### `Matrix.fromOrtho(left, right, bottom, top, near, far)`
Creates an orthographic projection matrix.

**Arguments**: projection range parameters

**Return value**: `Matrix` object

##### `Matrix.fromPerspective(fovy, aspect, near, far)`

## Notes

1. **Coordinate system**: SakanaGL uses a right-handed coordinate system.

2. **Angle units**: All angles are specified in radians. Use `Math.DTOR` to convert from degrees to radians.

3. **Quaternions**: Rotation composition is applied from right to left (`q1 * q2` applies `q2` first, then `q1`).

4. **Matrices**: Stored in column-major order. Compatible with OpenGL.

5. **Transform**: `Transform + Transform` composes hierarchical transforms.

6. **Bounding boxes**: `Rect3D` is represented by a center coordinate and radii (not minimum and maximum coordinates).

7. **Camera**: `isInside()` does not work correctly unless `updatePlanes()` is called first.

8. **Operator overloading**: Operators such as `+`, `-`, `*`, `/`, `|`, `^`, and `<<` are overloaded in many classes.

9. **Destructive operations**: Methods such as `add()`, `sub()`, and `mul()` modify the object itself. Use operators (`+`, `-`, `*`) to create new objects.
